# AI 客服历史案例

## 使用边界

历史案例仅用于辅助理解相似场景和方案方向，不能直接作为当前客户可交付能力的证明。

如果历史案例中的能力涉及定制开发、特殊接口或客户专属流程，必须标记为定制能力或待人工确认。

## 案例 A：电商客户 AI 客服

### 客户背景

某电商客户每天有大量商品咨询、订单查询和退换货政策咨询，人工客服重复工作量高。

### 客户需求

1. 商品咨询自动回答。
2. 退换货政策自动回答。
3. 订单状态查询。
4. 投诉场景转人工。

### 方案实现

1. 商品咨询通过商品知识库实现。
2. 退换货政策通过客户提供的售后政策文档实现。
3. 订单状态查询通过客户订单系统 API 对接实现。
4. 投诉场景通过工单系统创建人工跟进任务。

### 交付边界

订单查询依赖客户提供订单系统 API、接口文档和测试账号。

转人工依赖客户工单系统接口。

本案例没有采用私有化部署。

### 参考价值

该案例可作为电商 AI 客服方案参考，但订单查询和转人工能力仍需要根据新客户系统接口情况重新确认。

## 案例 B：制造业售后知识库助手

### 客户背景

某制造业客户需要让客服和售后人员快速查询产品手册、故障处理流程和售后政策。

### 客户需求

1. 产品手册问答。
2. 售后政策问答。
3. 常见故障处理建议。
4. 企业微信接入。

### 方案实现

1. 产品手册和售后政策导入知识库。
2. 常见故障处理建议基于客户提供的维修 SOP 生成。
3. 企业微信接入通过客户企业微信配置和消息回调完成。

### 交付边界

企业微信接入需要客户管理员权限和消息回调配置。

故障处理建议只作为客服辅助信息，不能替代工程师判断。

### 参考价值

该案例可作为内部知识库问答和售后支持场景参考，但企业微信接入需要根据客户环境确认。

## 案例 C：政企客户私有化部署

### 客户背景

某政企客户要求客服知识库和对话数据部署在客户自有环境中，并满足内部安全审计要求。

### 客户需求

1. 私有化部署。
2. 客服知识库问答。
3. 数据隔离。
4. 日志审计。

### 方案实现

1. 企业版 AI 客服进行私有化部署评估。
2. 客户提供服务器、网络环境和安全要求。
3. 双方确认日志留存、权限管理和运维责任边界。

### 交付边界

私有化部署需要交付负责人评估环境、安全要求和运维责任。

本案例中的安全审计配置属于项目交付范围内的专门评估结果，不代表所有私有化项目都默认支持同等配置。

### 参考价值

该案例可证明企业版 AI 客服可以评估私有化部署，但不能直接承诺新客户的私有化部署价格、交期和安全配置。

## 案例 D：多语言语音客服需求未落地

### 客户背景

某跨境电商客户希望 AI 客服支持英文、中文和日文语音客服。

### 评估结果

当前 AI 客服 MVP 未提供多语言语音客服标准能力。

该需求被标记为待产品和技术负责人评估，未纳入当前标准方案。

### 参考价值

该案例说明多语言语音客服不能作为当前标准能力承诺。
