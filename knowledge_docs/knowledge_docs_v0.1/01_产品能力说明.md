# AI 客服产品能力说明

## 1. 产品定位

AI 客服用于帮助企业处理高频客户咨询，适用于电商、零售、消费品、企业服务等需要处理大量重复问答的业务场景。

AI 客服的核心目标是降低人工客服重复咨询压力，提升常见问题响应效率，并在复杂问题或高风险问题中协助转交人工客服处理。

AI 客服输出内容定位为客服辅助回复和初步处理建议，不替代企业对客户作出最终业务承诺。

## 2. 标准支持能力

### 2.1 商品咨询

AI 客服标准支持基于商品知识库回答商品咨询问题，包括商品规格、使用方式、适用场景、基础参数、售后规则入口等。

前提条件：

1. 客户需要提供商品知识库或商品资料。
2. 商品资料需要保持更新。
3. 涉及库存、实时价格、实时促销等动态信息时，需要对接客户业务系统。

### 2.2 政策问答

AI 客服支持基于企业政策知识库回答退换货政策、售后流程、会员规则、服务条款等问题。

该能力属于可配置支持能力，需要客户提供最新政策文档，并由客户确认政策内容的有效版本。

### 2.3 知识库问答

AI 客服支持从企业上传的 FAQ、政策文档、商品文档和服务手册中检索信息，并基于检索结果生成回答。

回答应尽量基于知识库引用来源。如果知识库没有相关内容，AI 客服应提示未找到依据，而不能自行编造答案。

### 2.4 多轮追问

AI 客服支持在用户问题不完整时进行多轮追问，例如补充订单号、商品型号、问题场景、使用对象等信息。

多轮追问用于澄清需求，不应替代产品能力判断或售后规则确认。

## 3. 需要系统对接的能力

### 3.1 订单状态查询

AI 客服可以支持订单状态查询，但该能力依赖客户订单系统 API 对接，不属于纯知识库问答能力。

交付前提：

1. 客户提供订单系统 API。
2. 客户提供接口文档、鉴权方式和测试账号。
3. 双方完成订单字段映射和接口联调。
4. 客户确认可以向 AI 客服开放订单查询所需的数据权限。

方案表达建议：

> 方案可通过对接客户订单系统 API 支持订单状态查询，具体范围和联调周期需在实施阶段确认。

### 3.2 物流进度查询

AI 客服可以支持物流进度查询，但通常需要对接客户订单系统、物流系统或第三方物流查询接口。

如果客户未提供物流接口，AI 客服不能直接承诺可查询实时物流进度。

### 3.3 转人工

AI 客服支持在特定场景下触发转人工，例如投诉、情绪激动、连续未解决、用户要求人工、问题超出知识库范围等。

转人工能力通常依赖客户现有客服系统、工单系统或在线客服渠道是否开放接口。

交付前提：

1. 客户现有客服系统支持人工接入。
2. 客户提供转人工接口或工单创建接口。
3. 客户确认转人工触发规则和服务时段。

## 4. 部署能力

### 4.1 SaaS 部署

AI 客服标准支持 SaaS 部署，适合快速验证和一般客服场景。

### 4.2 私有化部署

AI 客服企业版支持私有化部署，但需要交付负责人评估客户环境、安全要求、数据隔离要求和部署资源。

私有化部署不能在初版方案中直接承诺交期和价格，必须进入人工确认。

方案表达建议：

> AI 客服企业版可评估私有化部署方案，具体部署条件、交付周期和费用需由交付负责人进一步确认。

## 5. 暂不支持或证据不足的能力

### 5.1 多语言语音客服

当前 AI 客服 MVP 不支持多语言语音客服能力。

如果客户提出多语言语音客服需求，应标记为待产品或技术负责人确认，不能写入确定性方案。

### 5.2 自动生成最终报价

AI 客服不支持自动生成最终报价。

报价涉及商务规则、实施工作量、客户定制范围、折扣审批和合同条款，必须由售前或商务负责人确认。

### 5.3 自动承诺交期

AI 客服不支持自动承诺交期。

交期受知识库准备、系统对接、接口联调、私有化部署、客户侧资源投入等因素影响，必须由交付负责人确认。

| --- | --- | --- |
| 商品咨询 | standard_supported | 基于商品知识库回答 |
| 退换货政策问答 | configurable_supported | 需要客户提供政策知识库 |
| 订单状态查询 | integration_required | 需要订单系统 API |
| 物流进度查询 | integration_required | 需要物流或订单接口 |
| 转人工 | integration_required | 需要客服系统或工单系统接口 |
| 私有化部署 | configurable_supported | 企业版支持，但需交付确认 |
| 多语言语音客服 | unsupported | MVP 暂不支持 |

| 确定交期 | unsupported | 必须人工确认 |
