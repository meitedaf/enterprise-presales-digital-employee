# AI 客服技术方案与系统对接说明

## 1. 总体技术方案

AI 客服通过企业知识库、对话模型、业务系统接口和人工协同机制完成客户咨询处理。

典型流程：

1. 用户提出问题。
2. AI 客服识别问题类型。
3. 对知识类问题，检索企业知识库并生成回答。
4. 对业务数据类问题，调用客户业务系统 API 获取实时数据。
5. 对高风险或无法处理的问题，触发转人工或创建工单。

## 2. 知识库接入

AI 客服支持接入以下知识来源：

1. 商品资料。
2. FAQ。
3. 退换货政策。
4. 售后服务手册。
5. 会员规则。
6. 企业内部客服 SOP。

客户需要确认上传文档的版本、有效期和适用范围。

如果知识库内容过期或缺失，AI 客服可能无法给出可靠回答，应提示未找到依据或要求人工确认。

## 3. 订单系统对接

订单状态查询属于业务系统对接能力，不属于标准知识库问答能力。

客户需要提供：

1. 订单查询 API。
2. API 鉴权方式。
3. 测试账号。
4. 订单号字段说明。
5. 订单状态字段说明。
6. 错误码说明。
7. 查询频率限制。

AI 客服可以根据用户提供的订单号调用订单系统 API，并将返回的订单状态转化为客服回复。

如果客户订单系统不开放 API，则不能承诺支持实时订单状态查询。

## 4. 物流系统对接

物流进度查询通常有两种实现方式：

1. 通过客户订单系统返回物流状态。
2. 通过第三方物流查询接口返回物流轨迹。

客户需要确认物流数据来源和接口调用权限。

如果物流接口无法提供实时数据，AI 客服只能回答物流政策或查询入口，不能承诺实时物流进度查询。

## 5. 转人工对接

转人工能力依赖客户客服系统或工单系统。

常见触发条件：

1. 用户明确要求人工客服。
2. 用户情绪激动或投诉。
3. 同一问题连续多轮未解决。
4. 问题涉及退款、赔偿、合同、投诉升级等高风险事项。
5. 知识库未找到可靠依据。

客户需要提供：

1. 客服系统接入方式。
2. 人工客服工作时间。
3. 工单创建接口。
4. 用户身份信息传递规则。
5. 转人工后的责任归属规则。

如果客户客服系统不支持接口接入，则转人工只能作为待确认能力。

## 6. 私有化部署技术条件

私有化部署需要评估以下条件：

1. 客户服务器或云资源。
2. 网络访问策略。
3. 数据隔离要求。
4. 日志留存要求。
5. 安全审计要求。
6. 运维责任边界。
7. 与客户内部系统的连接方式。

私有化部署交付周期和费用不能由 AI 客服自动承诺，需要交付负责人确认。

## 7. 技术依赖总结

| 需求项 | 技术依赖 | 交付风险 |
| --- | --- | --- |
| 商品咨询 | 商品知识库 | 资料过期会影响回答准确性 |
| 退换货政策问答 | 政策文档 | 政策版本需要客户确认 |
| 订单查询 | 订单系统 API | 接口开放和联调周期不确定 |
| 物流查询 | 物流接口或订单系统 | 数据实时性依赖外部系统 |
| 转人工 | 客服系统或工单系统 | 需要客户系统支持接入 |
| 私有化部署 | 客户部署环境 | 交付周期和安全要求需评估 |
